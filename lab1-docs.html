Lab 1: Booting Windows 11 Pro to USB

Creating a Bootable Pendrive

This lab demonstrates the process of using Rufus to write a Windows 11 ISO onto a USB flash drive to create a bootable installation media.

📌 Requirements

  • Rufus Software
  • Windows 11 Pro ISO File
  • USB Flash Drive (8GB or larger recommended)

Step 1: Download Rufus

Rufus is a free, open-source Windows utility for creating bootable USB drives — most commonly used to put an operating system installer (like Windows or a Linux distro) onto a USB flash drive so you can boot from it and install the OS.

📥 Download Rufus

Step 2: Download Windows 11 ISO

You will need the official or customized Windows 11 Pro ISO image file to write to your USB drive.

📥 Download Windows 11 Pro ISO
