🪟 Windows 11 Study Labs

Interactive, browser-based simulations of common Windows 11 Pro setup and administration tasks. Built for learning and practice — no VM, no ISO, no risk to a real machine.

✨ Features & Overview

Each lab is a single, self-contained HTML file with no build steps or external dependencies. Just open it in any modern web browser to experience a highly realistic, interactive Windows 11 environment.

🚀 Zero Setup Required

No VirtualBox, VMware, or large ISO downloads needed. Instantly launch from your browser.

🛡️ 100% Risk-Free

Practice disk partitioning, firewall blocking, and BitLocker encryption without risk to your real PC.

🎨 Highly Realistic UI

Authentic aesthetics, interactive context menus, Control Panel windows, and MMC snap-ins.

🌐 Fully Accessible

Runs entirely locally using pure HTML, CSS, and JavaScript.

💻 How to Use

  1. Clone this repository or download the ZIP file.
  2. Extract the files to your local machine.
  3. Click on any of the labs above from this dashboard.
  4. Inside each lab's documentation page, click the "Open Simulation" button.
  5. Follow the interactive "Lab Guide" panel on the screen to complete the tasks.
