Lab 3: System Restore Point

Snapshot and Rollback Windows System Configuration

A Restore Point is a saved snapshot of your Windows system's state at a specific moment — like a "save file" for your operating system's configuration, so you can roll back if something goes wrong.

✅ What it actually saves:

  • System files and settings
  • The Windows Registry
  • Installed program information (drivers, some app configs)
  • System files needed to boot Windows

❌ What it does NOT save:

  • Your personal files (documents, photos, downloads) — restore points don't touch these.
  • It's not a full backup — think of it as "undo for Windows itself," not a file backup solution.

🛠️ Lab Step-by-Step Instructions

The configuration simulator is fully working, matching the real Windows environment. Follow these steps to configure your restore point:

  1. Right-click This PC → select Properties → System info page → click System protection.
  2. In the drive list, click a row to select it (e.g., C: or D:) — it will highlight to indicate selection.
  3. Click Configure → This opens "System Protection for Local Disk (C:)", where you can practice:
    • Using the Turn on / Disable system protection radio buttons (toggling this updates the On/Off status back on the main list).
    • Adjusting the Disk space usage slider with a live-updating usage bar and GB estimate.
    • Using the Delete button that clears all restore points for that drive (updates the System Restore wizard's list to "No restore points on this drive" if you check it).
  4. Click OK or Cancel at the bottom to finalize your configuration.
