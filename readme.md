# 🪟 Windows 11 Study Labs

Interactive, browser-based simulations of common Windows 11 Pro setup and administration tasks. Built for learning and practice — no VM, no ISO, no risk to a real machine.

## 🚀 Overview
Each lab is a single, self-contained HTML file with no build steps or external dependencies. Just open it in any modern web browser to experience a highly realistic, interactive Windows 11 environment. This project is perfect for IT students, system administrators, and cybersecurity beginners who want to practice OS configurations safely without breaking their actual systems.

## ✨ Features
- **Zero Setup Required:** No VirtualBox, VMware, or large ISO downloads needed.
- **100% Risk-Free:** Practice disk partitioning, firewall blocking, and BitLocker encryption without any risk to your real computer.
- **Highly Realistic UI:** Authentic Windows 11 aesthetics, interactive context menus, Control Panel windows, and MMC snap-ins.
- **Accessible:** Runs entirely locally in your web browser using pure HTML, CSS, and JavaScript.

## 💻 How to Use
1. Clone this repository or download the ZIP file.
2. Extract the files to your local machine.
3. Double-click any `lab.html` file to open it in your default web browser (Chrome, Edge, Firefox, etc.).
4. Follow the interactive **"Lab Guide"** panel on the screen to complete the simulated tasks.
*(Alternatively, you can host these files on GitHub Pages to access them online from anywhere).*
